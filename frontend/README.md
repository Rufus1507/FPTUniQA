# Frontend - University QA

Giao diện Web tương tác trực quan cho sinh viên tra cứu quy chế đại học, được xây dựng bằng **Streamlit**.

## Khởi chạy giao diện

```bash
uv run streamlit run frontend/app.py
```

Truy cập trên trình duyệt tại: `http://localhost:8501`
Đảm bảo rằng Backend API tại `http://localhost:8000` đang được bật trước khi gửi câu hỏi.
